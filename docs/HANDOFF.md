# RISKVERSE — запуск и комплект сдачи

## Проверенный способ запуска

Требуется Node.js 22.22+ и npm. Из корня распакованного проекта:

```powershell
npm ci
npm run build
npm start
```

Откройте http://127.0.0.1:8787: собранный сайт и AI API работают на одном сервере. Терминал должен оставаться открытым. При занятом порте задайте другой через `PORT`. Настройки публичного Node-хостинга приведены в [DEPLOYMENT.md](DEPLOYMENT.md).

Для учебной демонстрации ключ не нужен. Нажмите «Учебный пример», затем следуйте DEMO.md. Фото поставляется в public/demo; разметка и размеры подготовлены вручную.

Для полного сценария без нового AI-запроса нажмите «Пример с сохранённым AI». Он содержит настоящий сохранённый ответ Gemini от 25 октября 2026; интерфейс помечает его как сохранённый, геометрия остаётся учебной. После открытия предыдущую работу можно вернуть из архива аудита.

Для настоящего AI скопируйте .env.example в .env.local, вставьте ключ Gemini API в GEMINI_API_KEY и перезапустите dev-сервер. При наличии обоих ключей выбирается Gemini; OpenAI остаётся запасным вариантом. Ключ не вводится в исходники или браузер. Квота тарифа ограничена и может меняться. Живые прогоны и результаты указаны в docs/AI_EVALUATION.md; перед выступлением проверьте доступность квоты и наличие сохранённого ответа.

`npm run preview` показывает статическую сборку и не подключает AI API. Полный показ работает через `npm start`; для разработки используйте `npm run dev`. Публикация статического dist без собранного серверного маршрута /api не даёт работающего AI.

## Собрать проверяемую передачу

После завершения изменений:

```powershell
powershell -File scripts/prepare-release.ps1
```

Команда запускает тесты, production-сборку и измерения, затем создаёт отдельную папку и ZIP в output/releases. В комплект входят исходники, lock-файл, dist, инструкции, лицензия фотографии, расчёты, журналы проверок и MANIFEST.json с SHA-256. Скрипт останавливается при ошибках или изменении исходников во время проверки. Уже созданные папки не удаляются и не перезаписываются.

В комплект также входят `dist-server`, конфигурация контейнера, презентация и выбранные публичные AI-кейсы. Для проверки распакованной папки выполните `powershell -File scripts/verify-release.ps1 -Path <папка-riskverse>`: скрипт проверяет хеши и отсутствие неучтённых файлов. Рядом с ZIP сохраняется его SHA-256.

В комплект по списку включаются только нужные папки: .env.local, node_modules, история браузерных проверок, пользовательские аудиты и снимки рабочего экрана из корня не копируются. Не помещайте личные данные или секреты внутрь src, server, public, scripts и docs: эти папки входят в поставку.

Зависимости устанавливаются через npm ci, поэтому для первой установки нужен интернет. Установка не входит в ZIP. Интерфейс использует системный шрифт; проверка полностью автономного запуска на новом компьютере не проводилась.

## Перед записью и отправкой

- Запустить распакованный комплект в другой папке и пройти DEMO.md.
- Пройти новый аудит со своим фото до объекта, двух маршрутов и перестановки; проверить базу сравнения.
- Дождаться статуса сохранения, перезагрузить страницу и проверить восстановление; скачать и заново открыть полный аудит.
- Получить настоящий AI-ответ на выбранном фото. Если это ещё не удалось, явно назвать демонстрацию ручной и не утверждать завершённость AI.
- Проверить читаемость на экране выступления; закрыть личные вкладки и уведомления перед записью.
- Указать автора фотографии и лицензию в кадре/материалах, используя public/demo/ATTRIBUTION.md.
- Сверить длительность видео, формат презентации, способ передачи и дедлайн с актуальным положением организатора. Этот документ не устанавливает конкурсные требования.
- Зафиксировать проверенную версию в Git после завершения параллельных изменений. Пакет не создаёт коммит автоматически.

Автоматические проверки не заменяют этот пользовательский прогон. Успешная сборка не подтверждает качество AI или готовность хостинга.
