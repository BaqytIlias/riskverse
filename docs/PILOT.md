# Проверка полезности на реальном участке

Этот протокол подготовлен для следующего этапа. Реальный пилот пока не проведён; пустые поля не означают нулевой результат.

## Что проверить

Может ли специалист быстрее подготовить объяснимое решение по изменению планировки и заметить новые проблемы, возникающие после перестановки? Качество распознавания фото проверяется отдельно от качества геометрических расчётов.

## Сравнение процесса

Подобрать несколько сопоставимых задач с известными размерами и заранее проверенными специалистом проблемами. Одни задачи выполнять обычным способом, другие — с RISKVERSE; чередовать порядок между участниками, чтобы повторное знакомство с одним и тем же кейсом не давало преимущество приложению. Записывать весь затраченный срок, включая подтверждение AI, исправление геометрии и экспорт. Отдельно фиксировать незавершённые попытки и их причины.

| Кейс | Участник | Способ / порядок | Полное время, мин | Подтверждённые проблемы найдены / всего | Ошибочные замечания | Новая проблема после перестановки замечена? | Причина незавершения |
|---|---|---|---|---|---|---|---|
| Заполнить | | | | | | | |

Сначала показать результаты каждой попытки и число участников. Затем сравнить время, пропуски и ложные замечания, сохранив различия сложности кейсов. Не выводить статистическую достоверность из маленькой демонстрационной выборки. Любое обещание экономии или повышения качества должно опираться на заполненные данные.

## Отдельная проверка AI

Взять разные фото: хорошо освещённый участок, сложное освещение, частично закрытые предметы и неподходящее изображение. До запроса специалист отмечает видимые релевантные объекты и наблюдения. Дату, модель, исходное фото и сырой проверенный результат сохранять в аудит вместе с исправлениями пользователя.

| Фото | Дата / модель | Время ответа | Корректные наблюдения | Пропуски | Выдуманные объекты / неподтверждённые выводы | Исправления человеком | Ошибка API |
|---|---|---|---|---|---|---|---|
| Заполнить | | | | | | | |

Заранее определить единицу подсчёта: наблюдение об одном объекте/ситуации. Повторные формулировки одного наблюдения считать один раз. Отсутствие средств или отказ API отмечать как недоступность, а не как нулевую точность. Ручной учебный пример и подменённые ответы тестов не включать в оценку AI.

## Проверка геометрии

Сопоставить известные размеры и позиции с введённой сценой. Проверить несколько контрольных точек пола, не использовавшихся как четыре угла калибровки. Записать ошибку координат в метрах, места с закрытой опорой и неплоским полом. Высоты проверять отдельным измерением. При заметном расхождении сначала исправить исходные данные, затем обсуждать результаты перестановки со специалистом.

## Что считать результатом

Подтверждением пользы станет воспроизводимый разбор конкретных изменений, проверенный специалистом, с измеренными затратами времени и ошибками. Вывод о снижении аварийности требует отдельного исследования; эти задания такого вывода не дают.
